# 雷达院奖学金专家/学生投票系统（可打包 EXE）

按你的要求，本版本做了以下调整：
1. 删除了“候选人姓名手动输入接口”，沿用“导入问卷星结果自动识别候选人”。
2. 支持直接导入问卷星 `.xlsx` 文件（同时兼容 `.csv`）。
3. 解决 CSV 编码问题：自动尝试 `utf-8-sig / gbk / gb18030 / utf-8`，避免 `utf-8 codec can't decode ...` 报错。
4. 新增“投票人权重接口”：可输入“2、您的姓名”字段对应姓名与权重，对该投票人的票数按权重计算。

## 已适配的问卷星结果格式

固定按列读取：
- 第7列：排序结果（例如：`李喆，特种雷达→赵泽玮，民用雷达→...`）
- 第8列：`2、您的姓名`（用于权重匹配）

排序解析规则：
- 以多种分隔符分隔（如 `→`、`->`、`┋`、`|`、`｜`、`;` 等），前到后即第1到第N名；
- 每段取逗号（`，` 或 `,`）前的姓名作为候选人名。

## 权重使用方式

- 在界面“特定投票人权重设置”中输入：
  - 投票人姓名（与第8列一致）
  - 权重（如 1.2、2、0.8）
- 导入文件时会自动匹配并应用该权重。
- 未设置权重的投票人默认权重为 1。

## 使用步骤

1. 填写专家/学生问卷链接并生成二维码。
2. 现场扫码投票。
3. 导出问卷星 `.xlsx`（或 `.csv`）结果。
4. 可先设置特定投票人权重。
5. 导入专家文件、导入学生文件。
6. 点击结算查看最终排名。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 打包 EXE（Windows）

> Windows 文件名不能包含 `/`，因此 EXE 名称使用“专家学生”连写。

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name "雷达院奖学金专家学生投票系统"
```

打包后 EXE 在：

```text
dist/雷达院奖学金专家学生投票系统.exe
```
