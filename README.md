# 在线投票统计系统（可打包 EXE）

这是一个桌面版投票统计工具，满足 7 人专家/学生综合排名规则。

## 关于“自动创建问卷星链接”

目前问卷星没有稳定公开的“自动创建问卷并返回链接”接口，
因此本版本提供**半自动方案**来尽量减少操作：

- 在 EXE 内直接录入 7 位候选人姓名。
- 一键复制“问卷题目模板”到剪贴板。
- 一键打开问卷星官网创建页面。
- 填入问卷链接后自动生成二维码给手机扫码。
- 投票结束后导入 CSV 自动结算。

## 使用流程（已简化）

1. 在软件中输入候选人姓名，点击“应用候选人”。
2. 点击“复制问卷星题目模板”。
3. 点击“打开问卷星创建页”，登录后新建“专家票/学生票”两份问卷，并粘贴模板。
4. 将两份问卷链接贴回软件，点击“生成二维码”。
5. 现场扫码投票。
6. 在问卷星分别导出专家/学生 CSV，导入软件结算。

## CSV要求

- CSV 表头必须包含当前候选人姓名的 7 列（与软件中姓名一致）。
- 每行必须是 1~7 且不重复，否则会提示导入失败。

## 结算规则

1. 先结算专家总分（分数越低排名越高）。
2. 再结算学生总分并得到学生排名。
3. 按学生排名对专家总分减分：第1名减7，第2名减6...第7名减1。
4. 按调整后的专家总分输出最终排名（分数越低越好）。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 打包 EXE（Windows）

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name vote_app
```

打包后 EXE 在：

```text
dist/vote_app.exe
```
