# 雷达院奖学金专家/学生投票系统（可打包 EXE）

按你的要求，本版本做了以下调整：
1. 删除了“候选人姓名手动输入接口”，沿用“导入问卷星结果自动识别候选人”。
2. 支持直接导入问卷星 `.xlsx` 文件（同时兼容 `.csv`）。
3. 解决 CSV 编码问题：自动尝试 `utf-8-sig / gbk / gb18030 / utf-8`，避免 `utf-8 codec can't decode ...` 报错。
4. 新增“投票人权重接口”：可输入“2、您的姓名”字段对应姓名与权重，对该投票人的票数按权重计算。


## Top-X 投票说明（重要）

### Top-X 次数统计功能
- 按钮位置：在“初评（权重设置 + 专家文件导入）”这一栏。
- 该功能**不计算名次分**，只统计“被多少位投票人选中”。
- 权重会生效：若某投票人权重为2，则其“选中次数贡献”为2。
- 例如：10个评委里李涌睿被选中10次=10分；王国庆被选中8次=8分；按次数从高到低排序。


当问卷是“从17人里选前7名”这类 Top-X 投票时，不同投票人选择集合不一致是正常现象。
本系统已支持该场景：
- 每条记录只需包含该投票人选出的前X名顺序；
- 未被该票选中的候选人，自动按“该票末位+1”计分（例如投前7名，则未入选按8分）；
- 因此不会再因为候选人集合不一致而整文件失败。

## 已适配的问卷星结果格式

固定按列读取：
- 第7列：排序结果（例如：`李喆，特种雷达→赵泽玮，民用雷达→...`）
- 第8列：`2、您的姓名`（用于权重匹配）

排序解析规则：
- 以多种分隔符分隔（如 `→`、`->`、`┋`、`|`、`｜`、`;` 等），前到后即第1到第N名；
- 每段支持 `姓名，单位` 与 `姓名-单位` 两种主格式（也兼容中文/英文符号变体），自动提取姓名。

## 权重使用方式

- 在界面“特定投票人权重设置”中输入：
  - 投票人姓名（与第8列一致）
  - 权重（如 1.2、2、0.8）
- 导入文件时会自动匹配并应用该权重。
- 未设置权重的投票人默认权重为 1。

## 使用步骤

1. 填写专家/学生问卷链接并生成二维码。
2. 现场扫码投票。
3. 导出问卷星 `.xlsx`（或 `.csv`）结果。
4. 可先设置特定投票人权重。
5. “初评”行可做：权重设置、导入专家文件、重置数据。
6. “终评”行可做：导入专家文件、导入学生文件、重置数据、结算排名。

> 每次导入同类文件会先清空该类历史记录（专家导入会覆盖之前专家记录，学生导入会覆盖之前学生记录），不会累加旧文件数据。


> 若导入文件中存在少量无效排序行（如重复姓名、无法解析），系统会自动跳过并提示数量，不会整文件失败。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 打包 EXE（Windows）

> Windows 文件名不能包含 `/`，因此 EXE 名称使用“专家学生”连写。

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name "雷达院奖学金专家学生投票系统"
```

打包后 EXE 在：

```text
dist/雷达院奖学金专家学生投票系统.exe
```
