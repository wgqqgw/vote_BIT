# 在线投票统计系统（可打包 EXE）

这是一个桌面版投票统计工具，满足 7 人专家/学生综合排名规则。

## 已改为“问卷星联动方案”（不使用 ngrok）

你提到对 ngrok 安全性有顾虑，因此本版本改为：
- 由问卷星负责在线投票采集；
- 本软件只做两件事：
  1) 显示问卷星链接二维码（给现场扫码）
  2) 导入问卷星 CSV 结果并自动结算排名。

这样就不需要在本地启动公网隧道。

## 使用流程

1. 在问卷星建两个问卷：
   - 专家投票问卷
   - 学生投票问卷
2. 两个问卷都设置 7 个候选人排名题（值为 1~7 且不重复）。
3. 把两个问卷链接粘贴到本软件，点击“生成二维码”。
4. 现场扫码投票（手机可直接访问问卷星）。
5. 投票结束后在问卷星分别导出专家/学生 CSV。
6. 在本软件点击“导入专家CSV”“导入学生CSV”，最后点结算按钮得到最终排名。

## CSV要求

- CSV 表头需包含以下列名（完全一致）：
  - `候选人1` `候选人2` `候选人3` `候选人4` `候选人5` `候选人6` `候选人7`
- 每行必须是 1~7 且不重复，否则会提示导入失败。

## 结算规则

1. 先结算专家总分（分数越低排名越高）。
2. 再结算学生总分并得到学生排名。
3. 按学生排名对专家总分减分：第1名减7，第2名减6...第7名减1。
4. 按调整后的专家总分输出最终排名（分数越低越好）。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 打包 EXE（Windows）

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name vote_app
```

打包后 EXE 在：

```text
dist/vote_app.exe
```
