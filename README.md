# 在线投票统计系统（可打包 EXE）

这是一个桌面版投票统计工具，满足 7 人专家/学生综合排名规则。

## 核心说明（根据你的需求）

本系统的“扫码投票”含义是：
- 在桌面软件中展示二维码；
- 专家或学生用自己的手机扫码，打开投票网页并提交；
- 投票结果实时进入桌面软件中，方便你后续一键结算。

## 手机 4G/5G 访问（非局域网）

软件支持两种模式：
- **公网模式（默认）**：自动创建公网址（ngrok 隧道），手机用 4G/5G 也能访问投票页。
- **局域网模式**：仅同 Wi-Fi/同网段内可访问。

建议在你说的网络环境下优先用“公网模式”。

### 公网模式失败时的处理（已针对 EXE 优化）

如果出现类似“公网地址创建失败”错误：
1. 先切换到局域网模式应急使用；
2. 或手动下载 `ngrok.exe`，放到：
   - `C:\Users\你的用户名\.vote_app\ngrok.exe`
3. 再回到公网模式点击“启动手机投票服务”。

> 新版程序会优先使用上述固定路径，避免在某些电脑上自动下载时出现写入异常。

## 功能

- 启动投票服务后自动生成两个二维码：
  - 专家投票二维码
  - 学生投票二维码
- 手机扫码后进入网页投票：对 7 名候选人提交 1~7 且不重复的排名。
- 桌面端实时接收票数并显示“第几票已收到”。
- 结算规则：
  1. 先结算专家总分（分数越低排名越高）。
  2. 再结算学生总分并得到学生排名。
  3. 按学生排名对专家总分减分：第1名减7，第2名减6...第7名减1。
  4. 按调整后的专家总分输出最终排名（分数越低越好）。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

启动后：
1. 选择“公网(手机4G/5G可访问)”；
2. 点击“启动手机投票服务”；
3. 让专家/学生扫码对应二维码投票。

## 打包 EXE（Windows）

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name vote_app
```

打包后 EXE 在：

```text
dist/vote_app.exe
```
