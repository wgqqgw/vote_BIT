# 雷达院奖学金专家/学生投票系统（可打包 EXE）

当前版本沿用“问卷星链接 + 导入CSV结果”的流程，并已适配你提供的问卷星固定CSV格式。

## 已适配的问卷星CSV格式

按你描述的固定格式：
- 第1列：序号
- 第2列：提交答卷时间
- 第3列：来源
- 第4列：来源详情
- 第5列：来自IP
- **第6列：排序题结果**（例如：`李喆，特种雷达→赵泽玮，民用雷达→...`）
- 第7列：姓名题（可有可无，本系统不依赖）

系统会从**第6列**自动解析排序结果：
- 以 `→`（或 `->`）分隔名次（从前到后是第1到第N名）
- 每段里取中文逗号 `，`（或英文 `,`）前的姓名作为候选人名

## 使用步骤

1. 在软件里填写候选人姓名（当前默认6人），点击“应用候选人”。
2. 将专家/学生问卷链接粘贴到软件并生成二维码。
3. 现场扫码投票。
4. 投票结束后导出问卷星CSV。
5. 在软件中分别导入专家CSV、学生CSV。
6. 点击结算按钮查看最终排名。

## 结算规则

- 专家票：总分越低排名越高。
- 学生票：总分越低排名越高。
- 加权：学生第1名对应专家总分减N（N=候选人数），第2名减N-1...最后一名减1。
- 最终排名：按调整后的专家总分升序。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate   # Windows 用 .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## 打包 EXE（Windows）

> Windows 文件名不能包含 `/`，因此 EXE 名称使用“专家学生”连写。

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py --name "雷达院奖学金专家学生投票系统"
```

打包后 EXE 在：

```text
dist/雷达院奖学金专家学生投票系统.exe
```
